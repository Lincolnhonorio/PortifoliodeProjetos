Orientação para obter sua API Key no GROC

Siga os passos abaixo para gerar e utilizar sua API Key do GROC:

passo 1: Acesse o site groc.com.

passo 2: Passe o mouse sobre a aba Developer e clique em Free API Key.

passo 3: Na página que abrir, selecione + Create API Key.

passo 4: Dê um nome para sua nova API Key.

passo 5: Copie a API Key gerada.

passo 6: Cole a chave na caixa "Insira sua API Key Groc" dentro da interface do nosso agente e pressione a tecla enter.

Após isso, parabéns!
Seu agente estará funcionando. Você também pode utilizar chaves de outros provedores de IA, caso queira.
