# 🐍 SNAKE Agent – Agente de IA em Python

# Este projeto consiste em um agente de Inteligência Artificial desenvolvido em Python, com interface via Streamlit, capaz de responder perguntas e auxiliar no aprendizado da linguagem.

# Criação e ativação do ambiente virtual

# Abra o terminal, navegue até a pasta do projeto e execute:

conda create --name dsaec1 python=3.13


# Ative o ambiente:

conda activate dsaec1
# ou
source activate dsaec1

# Instalação das dependências

# Instale o pip (caso necessário):

conda install pip


# Instale as dependências do projeto:

pip install -r requirements.txt

▶️ Executando a aplicação
streamlit run snake_agente.py
